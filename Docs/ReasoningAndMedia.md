# Reasoning intensity and media compatibility

`thinkLevel: Double?` is sent to Chat Completions, Responses, Codex Responses or Anthropic Messages. `nil` leaves reasoning settings to `extraBody` and the service. For an explicit ratio, the SDK takes precedence over old reasoning settings and keeps independent settings such as structured output and reasoning context. Finite inputs are clamped to `0...1`; non-finite inputs act like `nil`.

Zero is a separate off state where supported. Otherwise it selects the lowest available tier, or leaves the request unchanged when the model has no control. Positive values evenly divide the range across a model's actual tiers, with exact internal boundaries in the higher tier. An unknown Chat/Responses model uses `none` and `minimal/low/medium/high/xhigh/max`; unknown Messages endpoints use `thinking` and `output_config.effort` rather than sending a Chat-only key.

## TokenDance

The [public catalog](https://tokendance.space/gateway/v1/models) listed 134 IDs on 2026-11-26, 75 with Chat Completions. The protocol list indicates *transport*, not input modalities. Dedicated OCR, speech, search and generation services are not treated as general-purpose chat; Seedream is still offered through its image-generation slot. Model IDs and aliases determine image and video capability. The gateway uses the original Chat route, including for MiniMax M3/M3.1-Flash. There is no gateway-wide input video schema documented: the SDK uses the provider-compatible content parts. In particular, GLM's model pages confirm video as a modality but do not document the Chat video block; the gateway-specific behavior therefore remains unverified. Text-only models do not receive image or video blocks.

Additional catalog families were checked against [MiMo](https://mimo.mi.com/static/docs/quick-start/usage-guide/text-generation/deep-thinking.md), [StepFun](https://platform.stepfun.com/docs/zh/guides/developer/reasoning.md), [Baidu Qianfan](https://cloud.baidu.com/doc/qianfan/s/6mh4stoyf) and [DashScope Ling](https://help.aliyun.com/zh/model-studio/antdigital). MiMo uses a switch and supports image/video on Chat; Step 3.7 and Step 5 use three tiers and accept image/video; ERNIE 5.5 Flash Preview is text-only with an off switch and three tiers; Ling 3.1 Flash is text-only and uses `enable_thinking`. Ling 3.0 uses the same rule as a compatibility assumption.

TokenDance does not publicly establish the effort fields or accepted values for Hy3/Hy4, LongCat, Spark X2.5, CogEvol or Dots3-Note. These IDs retain the generic fallback. Hy4 and Hy4 Flash are recognized for image input; video and Hy4 Preview image support are not assumed.
